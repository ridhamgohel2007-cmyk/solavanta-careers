## 🌟 Executive Summary & Mission
**Solavanta Careers** is an ethics-first career accelerator and placement platform designed specifically for international students (F-1 OPT, STEM OPT, H-1B, and UK Graduate Visa holders) and ambitious STEM professionals breaking into tier-1 tech and analytics roles.

Traditional consultancies often rely on dangerous practices like resume falsification, fraudulent references, and predatory 30%–50% ongoing salary cuts. **Solavanta Careers** replaces that broken model with:
1. **100% Authentic Production Codebases:** Capstones and GitHub microservices built to survive rigorous live technical screens.
2. **Direct W2 / FTE Placement:** Direct hiring contracts where candidates retain 100% of their base compensation, bonuses, and equity.
3. **1:1 Staff & Principal Mentorship:** Weekly live mocks with senior engineers from Google, Amazon, Bloomberg, and top fintech firms.
4. **Money-Back Interview Guarantee:** Contractual commitment ensuring candidates secure qualified interview loops.

## 💻 Tech Stack & Zero-Dependency Portability

- **HTML5:** Semantic, accessible (ARIA attributes, keyboard navigation ready), and SEO-structured.
- **Modern CSS3:** CSS Custom Properties (variables), CSS Grid, Flexbox, backdrop-filter glassmorphism, responsive media queries, and smooth hardware-accelerated animations.
- **Vanilla JavaScript (ES6+):** Zero external runtime libraries or npm dependencies required. Includes `IntersectionObserver` for counter animations, dynamic tab rendering, modal managers, form validation, and synthetic PDF handbook generation.

## ⚡ How to Preview & Run

### Option 1: Double-Click to Open
Simply double-click `index.html` in Windows Explorer to open it in **Google Chrome**, **Microsoft Edge**, or **Firefox**. All styles, fonts, and scripts will load immediately.

### Option 2: Local HTTP Server (Python)
If you prefer viewing through a local web server:
```powershell
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

### Option 3: VS Code / Live Server
Right-click `index.html` in VS Code and select **Open with Live Server**.
